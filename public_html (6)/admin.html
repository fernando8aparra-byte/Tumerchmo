Aún no se ha cargado el catálogo. Da clic en "Cargar catálogo".
Esto es solo para BUSCAR el ID y nombre real de un servicio en tu proveedor -- no coloca ningún pedido ni cobra nada. Da clic en cualquier tarjeta para ver todos sus datos. Con "＋ Agregar a técnicos" lo mandas al catálogo de precio de técnico (apartado "Crear / editar servicio"); con "＋ Agregar a tienda pública" lo mandas a "Servicios de tienda", que es lo que ve cualquier cliente en tumerchmo.com.

Software agregado
Configuración de DHRU
Tu usuario y API key de territorioremoto.com. Se guardan en Firestore, ya no están escritos en ningún archivo del código.
Configuración de Stripe
Se guardan en Firestore, nunca en el código. Encuéntralas en tu panel de Stripe → Developers → API keys, y el signing secret en Developers → Webhooks.
Configuración de Mercado Pago
Se guardan en Firestore. Encuéntralas en tu panel de Mercado Pago → Tu aplicación → Credenciales de producción (o de prueba). La clave secreta del webhook está en la sección "Webhooks" de tu aplicación.
Moneda configurada para este proveedor. El catálogo usa USD; cambiar esta opción no convierte los precios. Verifica que el servidor gestione correctamente el importe antes de activar cobros en otra moneda.
Configuración de PayPal
Se guardan en Firestore. Encuéntralas en developer.paypal.com → Apps & Credentials, tienes credenciales separadas para "Sandbox" (pruebas) y "Live" (real).
Configuración de Binance Pay
Se guardan en Firestore. Encuéntralas en merchant.binance.com → Developers → API → Generar API Key. Necesitas cuenta de comerciante de Binance Pay (proceso de aprobación aparte, no es instantáneo como Stripe/PayPal). El cobro siempre es en USDT (1 USDT ≈ 1 USD).
Notificaciones de compras/recargas (correo + WhatsApp)
Te avisa cada vez que un técnico compra un servicio o recarga saldo (Stripe/Mercado Pago/Binance). El correo funciona con solo llenar tu dirección abajo. WhatsApp necesita la API de WhatsApp Business de Meta -- ve el paso a paso más abajo.
Correo
WhatsApp Business API (Meta)
1) Crea una app en developers.facebook.com → agrega el producto "WhatsApp".
2) En WhatsApp → API Setup, copia el "Phone number ID" y genera un "Access token" permanente (System User).
3) En WhatsApp Manager → Message Templates, crea una plantilla de categoría UTILITY llamada admin_notificacion (idioma es_MX) con el cuerpo: Nueva actividad en F3RN4N: {{1}}, y espera a que Meta la apruebe.
4) Agrega tu número de WhatsApp (con código de país, sin +, ej. 526624639310) a la lista de números de prueba mientras no tengas la app en modo producción.
Publicar noticia
Aparece como aviso arriba del panel de técnicos (/tec/index.html). Si le pones fecha de expiración, desaparece sola después -- si la dejas vacía, se queda hasta que la desactives a mano.
